# Installation Guide

## Requirements
- Android smartphone (ARM64)
- Termux and Termux:Boot
- Debian PRoot
- Internet connection

## Installation
1. Install Termux.
2. Install proot-distro.
3. Install Debian.
4. Configure Nginx.
5. Install Jellyfin and File Browser Next.
6. Configure Python API and Manager.
7. Configure Cloudflare Named Tunnel.
8. Configure Termux:Boot for automatic startup.

## Security
Never publish Cloudflare tokens, passwords or private databases.
