# My Cloud Setup Guide

## Overview
My Cloud provides personal file storage and file management through a web browser.

## Configuration
- Service: File Browser Next
- Port: 8081
- Base URL: /cloud

## Storage
- Storage directory: /storage/emulated/0/Android-Server-Cloud
- Database: Stored separately from this GitHub repository.

## Access
My Cloud is accessed through the main Nginx dashboard using the /cloud path.

## Security
- Do not upload database files.
- Do not upload personal documents or photos.
- Do not expose usernames, passwords or authentication tokens.
