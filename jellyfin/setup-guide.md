# Jellyfin Setup Guide

## Overview
Jellyfin is used as the media streaming server in this Android Home Server project.

## Configuration
- Service: Jellyfin
- Port: 8096
- Base URL: /jellyfin

## Access
Jellyfin is accessed through the main Nginx dashboard using the /jellyfin path.

## Data and Configuration
Runtime configuration and media data are stored separately from this GitHub repository.

## Security
- Do not upload media files.
- Do not upload private configuration files.
- Do not expose authentication credentials.
